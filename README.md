# 潜客名单学习版

> 请勿使用 **Code → Download ZIP**。请从右侧 **Releases** 下载正式安装包。

## 下载与运行

1. 打开 Releases，下载 `lead-list-learning-edition-v2026.07.29-windows-x64.zip`。
2. 完整解压 ZIP，不要直接在压缩包内运行。
3. 首次使用双击 `首次安装.cmd`，等待安装完成。
4. 双击 `启动潜客名单.cmd`。
5. 浏览器打开 WebUI 后即可使用。
6. 需要停止时双击 `停止潜客名单.cmd`。

## 系统要求

- Windows 10/11 x64
- Microsoft Edge 或 Google Chrome
- 首次安装需要联网

当前版本：`v2026.07.29`
