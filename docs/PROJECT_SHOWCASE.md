# 项目展示说明

## 定位

Media Deep Researcher是供个人使用的 Windows 本地采集与分析软件。用户自己的 Agent 通过可下载的 Skill 与本地接口操作软件；软件承担可靠执行、数据保存和结果展示，不绑定某个模型或内置推理运行时。

## 本次独立实现

- 把浏览器会话内的操作升级为 SQLite 持久化队列，统一图形界面与 Agent 的任务状态。
- 建立事务内幂等回执与客户端请求日志，处理重复提交、重试和会话切换。
- 建立自由分析协议：固定输入快照、自定字段、分批处理、覆盖率和证据引用，不预设分析行业或人数。
- 在七平台 MediaCrawler 底座上保留本地定制功能，逐项合并上游修复，并将数据目录与运行环境隔离。
- 复用 MediaFlow 首页和窗口模式，接入 WinForms、WebView2、Velopack 和完整运行时，验证安装/卸载/重装的数据保留。

## 复用边界

采集核心来自 MediaCrawler；首页和桌面体验来自用户的 MediaFlow；Skill 的组织方式借鉴 Hermes ComfyUI；运行环境和安装技术采用成熟第三方组件。不要将这些上游能力描述成从零开发，也不要将整个项目宣传为 MIT 许可或可自由商用。

## 当前可用作展示的证据

- 登录会话升级基线 603 项自动测试通过、1 项跳过；本次发行另通过 53 项登录与禁用媒体下载回归及前端生产构建。真实平台端到端验证不以自动化数量替代。
- 界面、队列、自由分析与五类导出已通过合成数据闭环。
- 完整运行目录在中文/空格路径、无开发工具 PATH 条件下通过搬迁测试。
- Windows 原生窗口、托盘、单实例、安装/卸载/重装保留数据已在当前机器实测。

真实平台连续采集成功率、全新 Codex/Hermes 首次接入、干净 Windows 离线安装和跨版本升级仍未完成，不作为已实现的业绩指标。正式展示前以 VALIDATION.md 的最新验收结果为准。

## 演示流程

1. 展示首页任务台入口与「复制 Skill」，将复制的内容粘贴给本机 Agent。
2. 导入合成通勤数据，由外部 Agent 按自定义目标和字段提交分析。
3. 展示输入记录、证据与处理覆盖率。
4. 关闭页面后重新打开，验证任务与分析仍在。
5. 导出 Excel 或 Word，再展示项目架构、复用边界与验收记录。
