## Standards

- P1：恢复时漏掉 cancelling 探测，会永久占用队列。已将 running/cancelling 一并标记中断，保留清理未确认，HTTP 重开回归通过。

- P2：探测输入与状态输出缺少完整类型。已增加受约束请求模型及状态/操作返回类型。
- 启发式 possible Feature Envy：采集观察模块复用 Queue 私有数据库缓存。已集中至 database.worker_database，保持队列职责独立。

## Spec

- P1：探测目录创建失败可能终止队列。已纳入启动错误边界，区分 storage_error；后续普通任务仍能完成。
- P1：七平台原生返回结构不同，已解析成列表的路径失去终页元数据。已在解析前记录原始结构白名单；七平台真实客户端加受控网络适配检查通过。
- P1：取消中探测重开后未终结。与 Standards 对应修复相同，独立保留两轴发现。
- P1：评论异常包装丢失 Retry-After。三处包装均保留，测试确认服务端两小时要求不会降为默认一小时。
- P1：显式重新登录更换账号时无法更新租约绑定。登录允许更新；普通采集换账号仍阻断。真实 HTTP、浏览器及受控认证适配检查分别验证两种行为。
- P1：浏览器启动超时后取消 future 未确认清理。增加串行 abort_probe 确认，在剩余总预算内完成；不能确认时报告 cleanup_complete=false。
