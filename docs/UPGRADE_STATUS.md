## 新版接口

FastAPI /api/v1 提供任务、数据、分析、产物、设置和诊断。桌面与 Skill 使用同一队列。SQLite 写操作与幂等回执同一事务提交；任务与分析进度不依赖网页会话。

原始记录保留内容版本；分析创建时固定输入快照。Agent 可以自定 Schema，也可不指定 Schema。证据引用必须指向该分析的输入。通用采集恢复采用重新请求加数据去重；各平台并非全部支持精确远端游标续跑。
