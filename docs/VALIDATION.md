安装验收第一轮曾失败：测试在卸载进程退出后立刻重装，遇到 Velopack 延迟三秒执行的目录清理。已修正验收脚本，等待安装目录完全清理后再重装，第二轮完整通过。第一轮日志保留在 `.cache/installer-smoke.log`，第二轮在 `.cache/installer-smoke-second.log`。此记录不等于跨版本升级或故障回滚已通过。

## 可复验命令

```powershell
uv sync --locked --python 3.11.16
uv run python -m pytest tests -q
npm.cmd --prefix webui ci
npm.cmd --prefix webui run build
uv run python tests/desktop_smoke.py
uv run python tests/portable_smoke.py
```

后两项需要先构建完整 `build/MediaWorkbench` 目录。界面测试与客户端测试的参数说明见对应 `tests/ui_smoke.py` 和 `tests/client_smoke.py`。测试使用独立数据目录，不复用个人社媒会话。
