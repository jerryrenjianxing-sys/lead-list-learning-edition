# 媒体下载移除记录

2026-09-22，按用户要求取消 Media Deep Researcher 的图片、视频文件下载功能。

- 新旧采集页面都移除下载选项、配置字段及文案；Skill 不再提供下载参数。
- 请求模型和 OpenAPI 不再包含 `enable_media`。为兼容旧客户端，收到该字段时忽略它；能力发现中 `media` 固定为 `false`。
- 新建、恢复和领取任务时清除旧下载选项。工作台执行器和旧版接口执行器均显式传入 `--get_media false`，旧任务或上游默认配置无法重新启用下载。
- 保留上游 MediaCrawler 的独立命令行实现，方便后续同步；它不属于工作台提供的能力。
- 不删除已有采集记录、附件、登录会话或已经下载的文件。原始内容中的来源链接仍可用于分析和证据引用。

## 验证

- 130 项相关自动化测试通过，包含新旧接口、旧任务恢复、七平台执行器参数、登录、历史记录清理及数据保留。
- 前端构建通过；浏览器验证下载选项消失、单条和批量清理、恢复、刷新、明暗主题及窄屏，无页面脚本错误。
- Skill 验证通过。本机安装版本已同步；更新前已备份数据库，更新后的任务、数据、分析和成果清单一致。
- “汇川技术”原任务在关闭下载后恢复为第 3 次运行，复用已验证的抖音登录；原有 1,164 条记录保留。恢复后的实测中，已有 29 个媒体文件的名称、大小和修改时间保持不变。

上述实际记录数量是检查时的快照。该整批采集仍在后台运行，不能将恢复验证当作整批采集完成；`release` 中旧安装包尚未重新打包，本次同步的是源码与本机安装版本。
