# 平台登录反馈与自动勾选

本次调整针对 Media Deep Researcher 本地安装版本。安装包归档尚未重新生成，源码和本机安装目录会随本次修改同步。

## 行为

- 导航及入口统一为“平台登录”。点击后留在当前页，立即显示提交状态；每个平台独立排队、禁止重复点击，并展示等待时间、扫码和手机确认指引。
- 七个平台在实际浏览器创建、认证检查、二维码发布和认证结果处更新进度。浏览器创建完成即报告，页面使用 DOM 就绪条件，避免等广告或持续请求加载完成才认为浏览器启动。
- 同平台活动登录任务（包括采集任务中的登录阶段）在数据库事务中去重；创建、恢复和跨客户端重复请求返回已有任务。
- 平台认证与浏览器缓存分别保存。只有服务器认证成功才可自动勾选；手动取消勾选不受轮询影响。重开恢复最近成功记录，实际采集前再次验证。
- 登录任务不创建空数据集、不继承采集条件、媒体下载或资料补全选项。认证完成后退出登录任务，不继续采集。
- 登录失败、关闭窗口、取消、超时及网络异常分别记录。正常退出或成功日志不能替代认证确认。旧缓存和旧版“已完成”任务不直接升级成已登录状态。

## 数据及接口

SQLite 从版本 1 迁移到版本 2，迁移前使用 SQLite 备份 API 保存一致快照，备份位于用户数据目录的 `backups`。已有数据、任务和浏览器账号缓存保留。

新增 `platform_auth` 和 `login_progress`。进度按任务和运行次数保存；已停止任务及旧运行次数的更新被拒绝，延迟发布的二维码不会将已验证状态退回等待扫码。没有保存额外的 Cookie、账号 ID 或平台响应内容。

`GET /api/v1/platforms` 增加真实 `login_state`、`verified_at`、`auth_reason` 和 `login` 对象。状态为 `not_checked/authenticated/logged_out/unknown`；最近成功验证时间会保留，但只有当前 `authenticated` 才表示可默认选中。原有字段仍可用。登录任务 `dataset_id` 为 null；调用方应使用创建或恢复响应返回的任务 ID。

自动化覆盖：

本次全套测试为 543 通过、1 跳过（2 条已有依赖弃用提示）；最终补充的采集错误回归与认证模块另行验证。前端构建通过，7 组浏览器交互检查通过且没有页面脚本异常。

- 数据库升级备份、重复启动、并发提交与恢复去重、复用采集中的登录阶段、旧运行次数拒绝、任务恢复与状态持久化。
- 七个平台的成功、缓存恢复、明确未登录、无法确认及异常分支；正常退出及“成功”日志不产生认证结果。
- 构建后的真实 Chromium 页面：首次不选平台、提交即时提示、连续点击、每个平台独立排队、阶段提示、手动取消勾选不被刷新覆盖、重载恢复、失效取消、请求超时后查找已提交任务、键盘操作和 320/390px 宽度、明暗主题。

本机真实平台验证（2026-09-22）：

| 路径 | 结果 |
|---|---|
| 原有抖音缓存检查 | 未通过认证恢复。服务器 self-profile 接口实际返回 `status_code: 8`（用户未登录），未将缓存或旧任务成功当作登录成功。 |
| 抖音登录二维码与提前关闭窗口 | 确认进入等待扫码阶段；关闭本次任务页面后提示浏览器已关闭，任务失败，没有生成已登录记录。 |
| 小红书登录二维码与取消 | 确认排队、浏览器创建、验证、等待扫码、停止和取消；未误报登录成功。 |
| 手机扫码确认后的认证成功与缓存恢复 | 待用户实际完成手机确认后验证；自动化模拟不计为真实通过。 |
| 其余五个平台的真实扫码 | 未执行，本次不标记通过。 |

首次抖音尝试发现上游主页导航等待 `load` 导致超时；已改为 `domcontentloaded`，并分离浏览器创建与页面加载反馈。后续实际进入了登录扫码阶段。

本机更新前后检查既有数据集、记录数、任务、分析和成果的 ID；更新本身不改变这些记录。真实验证产生的登录任务留在任务历史，便于追溯。构建文件哈希记录在安装目录 `build-manifest.json`；界面截图与自动化结果保存在本地 `.cache/login-review/`，不包含账号凭据。

## 恢复方式

版本 2 数据库不能交给只支持版本 1 的旧后台读取。需要回退时先退出软件，再恢复对应版本的应用文件与升级前数据库备份；保留当前数据库的副本。浏览器缓存不需要删除。恢复旧备份会回到其保存时刻，不能覆盖更新之后仍需要保留的任务或成果。

## 认证接口依据

五个平台沿用仓库现有服务端认证查询。抖音增加对 self-profile 当前身份的确认，贴吧使用 `is_login` 服务端标志，不以本地 Cookie 是否存在判定成功。接口响应缺字段或受到网络、验证页干扰时保留“验证未完成”。

- 抖音同源 self-profile 使用方式参考 [OpenBiliClaw 原项目文档](https://github.com/whiteguo233/OpenBiliClaw/blob/main/docs/modules/cli.md)，未复制其源码；本机只记录响应字段形状和状态码，不记录身份内容。
- 贴吧 `is_login` 使用方式参考 [TiebaSignIn 原项目实现](https://github.com/Alcatraz-Zhang/TiebaSignIn/blob/feat/keepalive-liskin/tieba_client.py)，未复制其源码；本机尚未完成真实账号验证。
