# 0.5.6 安装包验收范围

行为来自已合并的0.5.4启动、重连及分析列表修复，见[修复验证记录](validation-0.5.4-desktop-reconnect.md)。本版增加版本与发行证据门槛，不合并此前0.5.5浏览器实验，不升级第三方依赖，不改变schema 6、API v1或采集规则。

## 发布前必需证据

- 完整Python回归、前端构建、Electron单元及页面集成检查。
- 干净源码构建的桌面、Python、安装包、更新包、源码和Skill版本一致；包内文件逐一校验并生成SHA256SUMS。
- 真实包内故障恢复：发生认证就绪检查失败后自动恢复；正常页面及手动打开页面的位置保留；清理完成，并记录实际Electron版本。对应ELECTRON_RECONNECT_RESULT.json。
- 桌面启动、退出、后台缺失恢复、Skill文件复制和独立运行自检。对应桌面、生命周期、Skill和SELF_TEST_RESULT.json。
- 0.4.3、0.4.4、0.5.4分别通过完整安装及原生更新路径，0.4.3回退单独排练；0.5.3已耗尽却假等待的旧状态修复继续验收。对应升级矩阵和ELECTRON_053_UPGRADE_RESULT.json。
- 使用新的私有0.5.7安装及更新夹具验证原生更新器；私有包不发布为公开版本。对应ELECTRON_NATIVE_UPDATE_RESULT.json。

发行附件中的JSON是本次实际执行结果。发布器拒绝缺少0.5.4任一路径、版本不一致、未完成清理或故障恢复未通过的证据；失败上传保留原草稿，不覆盖旧标签及已发布文件。

## 本机升级与任务

本机只安装从本次GitHub发行下载并核对哈希的官方包。正常退出后完整备份当时最新的数据、分析成果、原任务及浏览器档案；新版本连接同一资料库后核对完整保留情况，不恢复早期数据库备份。

用户原三个餐盒关键词沿用原任务、数据集及去重；先验证原账号和任务规则，再按新的明确续跑请求保存原生续接与一次有界复查重开。保持1／2／4小时、三次自动失败转人工、服务器更长等待优先、阈值999（至少1000条）、随机90–120分钟及一级二级评论配置。旧AI批次保持暂停。

合成验收、登录成功和操作受理都不能证明平台读取恢复。真实排队、采集、等待与入库变化分别记录；未完成的跨天、干净系统及真实平台稳定性不追认为通过。
