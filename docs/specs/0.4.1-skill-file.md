# 0.4.1：复制 Skill 文件与预览发行

用户确认0.4.0本机安装可用后，要求增加可改名的Markdown文件复制，并推送新版。此批准允许发布0.4.1预览版；0.4.0候选记录保留。真实TRAE/Codex/Hermes首用状态依然如实记录，不将文件剪贴板测试冒充真实Agent验收。

- 首页主要按钮复制真正的 `.md` 文件，支持Windows文件剪贴板；在支持附件粘贴的聊天框可作为文件发送。不自动发送消息。
- 保留原首页布局；提供复制文字备用入口和文件名编辑，默认 `Media Deep Researcher.md`。接受中文和空格；文件名不得成为路径、Windows设备名或其他扩展名。
- Markdown是本机接入入口，包含当前完整Skill绝对路径、随包Python、客户端和显式实例参数。改文件名不影响接入；辅助材料仍由安装维护，不将Cookie、Token和业务数据写入分享文件。
- 从现有AgentAccess生成同源Markdown，原connect/ZIP/markdown接口保持兼容。文件仅写入独立的本机分享目录；每次复制保留独立文件，旧剪贴板引用不会被后一次改名或复制覆盖。退出或升级不删除分享文件。
- 文件内容与原复制文字按同一接入契约生成，保留通用分析和按用户意图接续。文件发送不是安装标准Skill目录，不改变正式SKILL.md和显式调用策略。
- 新桌面桥只接受文件名。校验主窗口、主框架及精确本机来源；网页不能选择文件路径、内容或任意剪贴板格式。普通浏览器和旧桌面使用文字备用，明确显示真实复制类型。
- 验证沿用已批准的HTTP/已安装Skill和Electron公共seams：先红后绿；独立Windows CF_HDROP读取、真实Markdown/客户端接入、改名后原文件保留、错误来源和非法名字拒绝、文字备用、键盘/主题/小窗口。接收方聊天应用兼容性需单独实测。
- 版本唯一来源pyproject.toml=0.4.1，依赖/业务数据库保持不变。保留草稿核验、附件哈希、完整安装和原生升级验收；0.3.1公开基线升级到0.4.1及0.4.1到私有下一版隔离测试，随后本机0.4.0升级。
