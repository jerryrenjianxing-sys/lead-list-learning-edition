# 0.4.0 candidate acceptance specification

Approved 2026-10-19. Baseline public v0.3.1 (e90eee3). This version combines project normalization and Agent onboarding. Preserve the Electron/Python/SQLite/MediaCrawler stack, data, accounts, analysis freedom, API v1 and database schema 4. Freeze crawler/browser/runtime dependencies.

## Delivery boundary

Build and test 0.4.0 candidates, push modernization/0.4.0, and supply installer, portable with isolated launch, source, Skill, complete update, checksums and evidence by source commit. Do not publish a tag/Release, change the live update feed, or replace the user's daily installation. Fresh TRAE and Codex acceptance may follow candidate delivery and remains a public-release gate.

## Agent contract

- Homepage layout stays. Bootstrap locates current installed SKILL, bundled Python/client and exact discovery file; it invokes the native Python executable with --instance, no system-Python or execution-policy setup. ZIP is fallback.
- GET /api/v1/agent/handshake is authenticated and compact: product/version/api_version/instance_id/workspace_id/capability_revision/summary/help. No credentials, account details or business data. Instance changes per backend start; workspace is normalized data-root identity, independent of request receipts; capability revision excludes runtime/clock/account values.
- connect is light. Updated check proves authorization and preserves old important fields. Only handshake 404/405 permits legacy health/capabilities/protected settings fallback. No authorization bypass on 401/403.
- Once per client process, validate identity/authorization; do not retrieve full capabilities before every operation. At most one rediscovery; verify the same workspace, then query original receipt or replay same ID/body/scope. Cross-workspace recovery fails. Atomic journals never replace completed with pending.
- Errors have code, retryable and next_action without secrets. Keep generic API/upload/download, free schemas/goals/counts, and optional lead template.
- Connection card or capability question: light readiness and brief examples only. Given task: execute without repeated introduction. Whole-install/runtime diagnosis: full self-test. Platform-specific problems: targeted status first. No fixed question list.

## Diagnostics contract

SelfTests remains one controller with sequential internal local/network phase workers. Complete budget 180s = local125 + network45 + cleanup10; local-only170 + cleanup10. Spawn/stop belong to phase budgets; one absolute overall deadline. Phase selection is private, never a crawler worker option.

Keep real temporary runtime/browser, independent host and restart, synthetic queue/de-duplication, freshly distributed Skill, five exports and cleanup. Local phase shares one temporary Playwright/Chromium with separate closed contexts/pages. Never use account browser/data. Record import/spawn/browser/page/recovery timings.

Preserve completed steps on timeout; local result is incomplete. Unattempted network uses skipped, attempted=false and reason; actual platform restrictions/errors remain distinct. Cancellation/crash/restart identify owned phase PIDs, creation times and directory. Incomplete cleanup leaves safe recovery information.

## Workspace contract

Keep existing HTTP endpoints and result shapes. WorkspaceReadModel owns their projections. Refresh only visible needs: overview jobs/datasets/analyses/artifacts; jobs jobs/platforms; data datasets; analyses analyses/artifacts; platforms platforms; settings its own reads. Sections update independently, retain last good data, display local errors, and preserve in-progress editing.

## Normative outputs and checks

Provide actual entry/module map, six-term glossary plus lifecycle states, connection/receipt/diagnostic contracts, upstream revision and patch inventory, acceptance matrix. Perform interface-driven TDD; structural changes under green contracts and review. Standards and Spec reviews remain separate.

Test four public seams: first onboarding; business/recovery; diagnosis; desktop/upgrades. Cover wrong credential, stopped host, legacy/changed address, wrong workspace/protocol, Chinese paths/arbitrary cwd, connect with zero diagnostics/jobs/login/data writes, arbitrary analysis/evidence/exports, unknown response/restart/concurrent ID replay, budgets/cancel/crash/cleanup, sandbox/tray/theme/update bridge, isolated0.3.1→0.4.0 and0.4.0→private0.4.1. Preserve all existing regression guarantees.

Client cold/warm each >=20 samples, report stages and initial p95. Goals: warm authenticated readiness p95<=2s, cold client process<=5s; unmet goals are reported honestly. Fresh TRAE/Codex each >=3 trials with only homepage material; report median/max/tool count, no p95 from three trials. Hermes and real platform checks not executed stay pending. Candidate success is not public-release acceptance.
