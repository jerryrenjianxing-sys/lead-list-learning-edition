# 0.1.1 登录会话升级

日期：2026-09-22。目标为首次登录后自动保存、后续任务自动恢复，平台明确要求验证时再由用户操作。平台自身决定登录有效期，不能据本轮测试宣称永久免登录。

## 实现

- 后台线程统一持有一个有界面的浏览器、平台专用档案锁及任务租约；同平台复用，切换平台保存关闭，空闲五分钟关闭。采集子进程连接本机 CDP 并只释放自己的页面。普通启动使用最小化且不激活窗口；用户打开平台或登录验证时显示。
- 浏览器可执行文件与档案绑定。启动只重试原环境，不回退到空档案。迁移原有 CDP 档案，旧缓存不等于认证成功。存在的档案优先；缺失或确认损坏时才恢复匹配的有效备份，损坏档案先保留。已明确失效的快照不再恢复。
- 服务端认证确认后保存 Cookie、Local Storage、IndexedDB，Windows DPAPI 加密、刷盘后原子替换。普通浏览器档案可能不保留会话 Cookie，所以干净重开时只补回有效快照中缺失的会话 Cookie，不覆盖浏览器已有的新值。未添加通用 Session Storage 恢复。
- 最近成功认证与最近检查结果分开。检查最多三次、总预算三十秒；网络与未知结果不会自动触发扫码。失败或取消不覆盖最近有效快照，保存失败有独立提示与重试入口。文件与数据库提交之间发生异常或进程中断时，可回退到绑定一致的上一代加密快照；明确失效和忘记账号仍禁止恢复。
- 认证暂停记录原账号和会话代次。同一账号完成新认证且保存后，原任务/数据集最多自动续接一次；换账号或身份未知需要确认，主动停止不续接。小红书采集中登录失效/验证码回调会释放队列。
- 数据库 3→4 迁移前备份。接口新增账号摘要、保存情况、检查结果、人工确认任务，以及 check/open/login/forget 操作。账号 ID 仅内部散列比对，凭据不返回客户端。
- “忘记此账号”需要页面确认，平台正在使用时拒绝；删除该平台档案和快照，保留任务、数据与分析。Skill 改为直接提交采集，不要求每次先手动验证。

## 验证记录

最终完整自动测试 603 通过、1 跳过（142.82 秒）；包括已有采集/数据/分析回归。跳过项为需外部平台条件的旧媒体端到端测试。新增 Windows 实测使用隔离合成账号，覆盖 DPAPI、正常关闭后的会话 Cookie 恢复、损坏档案恢复、浏览器复用、工作进程断开不关闭共享浏览器及过期租约拒绝。七平台认证结果分支通过替身测试，不能替代七平台真实登录验收。

生产界面测试覆盖首次未选、认证后选择、手动取消不被轮询覆盖、网络异常保留账号、忘记确认与 Escape、明暗主题、320/390px 窄屏；无页面脚本异常。Skill 格式验证与前端构建通过。

本机安装已更新至 0.1.1，数据库结构为 4。更新前完成数据库备份，任务、数据集、分析、成果清单核对一致。安装版本实际页面检查通过，无脚本异常。原“汇川技术”测试采集已按用户要求停止，保留 6722 条记录，不自动恢复；含演示数据共 6728 条。

真实抖音检查复用了原 Chrome 和 `cdp_dy_user_data_dir`，平台返回明确未登录，任务正确转为 needs_login，未误报恢复成功。随后打开了扫码流程；用户选择稍后验证，已取消等待并保留档案。新快照尚未用真实账号生成，连续三次及重开真实账号恢复记为未完成（0/3），不能把旧版采集成功计入新版验收。

## 明确待验证

- 小红书、抖音各连续三次真实任务启动、软件重开后认证确认，其他五平台相同验收；不以合成浏览器测试代替。
- 各平台真实验证码、手机确认、账号切换、服务端失效的完整交互；昵称和稳定账号标识依平台实际响应，未知身份必须人工确认续接。
- 重启电脑、跨天保持登录、干净 Windows 10/11 与 DPI 组合、正式发行源升级/回滚。
- 旧版报告的未验收项仍有效。此版本是本地候选版，不标成全部平台已验收的公开正式版。

开发机证据放在 `.cache/session-research`、`.cache/session-upgrade`、`.cache/login-review`；包含个人数据的缓存不进入源码或安装包。
