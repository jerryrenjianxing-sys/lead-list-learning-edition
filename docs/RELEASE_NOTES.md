# Media Deep Researcher 0.4.1 预览版

- 首页「复制 Skill」复制真正的 `.md` 文件，可在支持文件粘贴的 Agent 中作为附件使用；「更多复制选项」支持中文文件名和「复制文字」备用。普通浏览器和旧桌面继续复制文字，提示区明确显示类型。
- 附件提供当前完整 Skill、内置 Python、客户端和实例的真实绝对路径，直接执行一次轻量连接。不包含凭据、Cookie 或业务数据；改文件名不影响接入，完整材料仍随软件维护。
- 沿用0.4.0的轻量授权握手、回执恢复、诊断阶段预算和按页读取任务台。没有研究目标时不创建任务；正常研究不自动执行整套自检。采集依赖、数据库和账号档案不变。
- 文件复制只接受文件名，限制当前主窗口与精确本机来源；拒绝路径、设备名、任意内容。每次创建独立分享文件，后续复制、退出及升级不会使旧引用失效。
- 版本由 GitHub 标签和 `pyproject.toml` 管理，沿用 win-preview、数据备份和用户点击升级。发布先核验完整安装、原生更新、桌面、自检和 Windows 文件剪贴板证据，再公开草稿附件；已发布同版本不覆盖。

本版经用户本机试用后批准作为预览推送，取代0.4.0仅交候选的当前交付限制。真实 TRAE、Codex 新会话各三次、Hermes及接收方文件粘贴兼容性尚未完成，不宣称通过；不支持附件粘贴时使用「复制文字」。安装包未签名；干净 Windows、真实平台连续采集及长期登录仍待验证。发布附件中的 JSON 和校验值记录实际构建结果，历史证据不冒充新版验收。

## 0.4.0 候选版历史说明

- 首页复制本机完整 Skill 和随包 Python 命令，显式绑定当前实例。轻量授权握手验证身份后直接执行用户任务；连接、能力介绍不触发自检。
- 客户端保留 v1 和旧服务兼容，只有握手 404/405 才回退；401/403 明确拒绝。重启后确认同工作区再恢复原请求回执，完成结果不会被并发请求覆盖。
- 诊断拆分本机、联网和清理阶段，固定总预算180秒，增加启动、导入、浏览器、页面及恢复计时。未执行的联网步骤明确标记跳过，本机超时不会冒充平台失败。
- 任务台按页读取，各区块独立显示失败并保留已有数据和编辑内容。
- 增加领域术语、行为契约、实际模块图、上游补丁清单和验收矩阵。本轮冻结采集依赖，不迁移业务数据库，不改变账号档案。

本版仅提供按源码提交区分的候选文件，不创建公开标签或 Release，不修改公开更新源，不自动升级日常安装。候选便携包解压后通过 `Start-Candidate.cmd` 隔离运行。完整安装包使用原产品身份，供验收及后续人工升级使用。

公开门槛仍包括真实 TRAE、Codex 新会话各至少三次首用验收；Hermes 未实测不标为通过。自动化和隔离运行证据见候选验证报告，不能代替真实平台、模型质量和干净 Windows 验收。

## 保留的 Electron 迁移能力

- Windows 桌面从 WinForms/WebView2 迁移到 Electron；保留首页、任务台、明暗主题动画、平台登录、运行自检和外置 Agent 接入。
- 保留单实例、托盘、关闭窗口后采集继续、明确退出时保存进度。兼容旧版激活与退出协议，避免两套桌面争用同一后台。
- 桌面仅连接同产品、同数据目录和同版本后台；发现旧后台时提示正常退出后重开。
- 安装包自带 Electron、Python、独立 Node 和采集浏览器，移除 WebView2 离线安装与 .NET Framework 桌面运行依赖。
- 延续原有 MediaWorkbench.Desktop 安装身份及 win-preview GitHub 更新通道；任务或自检忙时暂缓，安装前备份数据。
- 平台专用浏览器、账号档案、Windows 加密快照、数据目录和 API 保持兼容。本轮冻结采集依赖和浏览器版本。
- preload 只暴露受限更新操作，校验当前主页面；外部链接通过系统浏览器打开。
- 修复 Windows 深目录中成果导出和下载超过 260 字符的文件访问错误，保留原文件名与相对路径；任务栏标识与旧版快捷方式一致。
- Skill 同步桌面启动及版本冲突排障说明，客户端命令保持兼容；显式调用策略保留。

本版仍为预览版。本机自检通过不等于七个平台全部采集路径或模型分析质量通过。游客访问可能受平台限制，网络与平台实测单独记录。桌面迁移说明见 ELECTRON_MIGRATION.md。

0.2.0 用户可通过既有软件更新通道或完整安装包升级；0.1.1 用户仍需首次运行完整安装包接入更新通道。保留现有任务、数据和账号。0.2.0 的独立自检与更新记录保留在其原发行中；旧版发行不覆盖。

安装包未代码签名；干净 Windows 10/11 离线安装、跨天登录及真实账号连续恢复的完整组合验收仍待完成。
