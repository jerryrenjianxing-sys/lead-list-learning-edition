# Media Deep Researcher 0.2.0 预览版

- 设置页新增独立运行自检：检查本机环境、页面、后台队列、Skill、数据读写、五种导出和重开恢复。
- 自检可选择仅检查本机，或附带一次微博游客搜索和详情读取；只显示状态，不创建正式任务或研究报告。
- 自检使用临时数据与浏览器环境，结束清理；重复请求复用，支持取消和刷新恢复进度。
- Skill 新增 self-test 命令及说明，保持原有自由分析和可选潜客模板。
- GitHub 管理源码、版本及更新文件；桌面每二十四小时最多自动检查一次，用户点击下载和安装。采集或自检运行时暂缓安装，安装前备份数据。

本版仍为预览版。本机自检通过不等于七个平台全部采集路径或模型分析质量通过。游客访问可能受平台限制，网络与平台实测单独记录。

0.1.1 用户首次需运行本版完整安装包接入更新通道；以后在设置或托盘检查更新。保留现有任务、数据和账号。正式采集与登录规则不变。

安装包未代码签名；干净 Windows 10/11 离线安装、跨天登录及真实账号连续恢复的完整组合验收仍待完成。
