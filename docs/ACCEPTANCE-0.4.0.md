本轮已记录的 red→green：旧 overview 的一个成果接口 503 使任务及数据均不显示；分区读取后恢复其余成功内容。旧诊断页面不能将 attempted=false 明确表示为“未执行”；新增状态展示后通过。升级收集器先拒绝批准的 0.3.1→0.4.0 证据，CLI 先缺少 baseline 参数；修复后新旧版本契约均通过。测试针对真实可见行为及对外证据/参数，不将安装夹具替代真实安装。
