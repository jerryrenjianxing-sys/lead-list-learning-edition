# Media Deep Researcher 0.1.1 公开预览

日期：2026-09-22。发行标签：`v0.1.1-preview.1`。

这是原「潜客名单学习版」的后续版本。原仓库地址和 `v2026.07.29` 发行均保留；仓库现在同时提供完整开发源码和 Windows 预览包。保留 MediaCrawler 的 NON-COMMERCIAL LEARNING LICENSE 1.1，用途仍受该许可约束。

## 新版包含

- 七平台采集接口、本地持久化队列、数据管理、通用分析和多格式导出。
- 自带 Python、Node、采集浏览器及 WebView2 离线安装程序的 Windows x64 安装包。
- 外置 Agent 使用的完整 Skill；潜客分析作为可选模板，用户可自行定义分析目标。
- 独立平台登录流程、Windows 加密快照、会话恢复、认证暂停与同账号续接。
- 可撤销的任务记录清理、明暗主题、新 Logo、任务台和平台登录页面。
- 已移除应用媒体下载功能；本次打包也移除闲置的独立 FFmpeg/FFprobe，并补齐前端运行依赖的原始许可文件。

## 已有验证与边界

会话升级基线完整自动测试为 603 通过、1 跳过；具体情况见 [登录升级记录](LOGIN_SESSIONS.md)。发行附件记录本次源码和包的哈希及演示数据验证，合成数据不会被当成真实平台验收。

本次发行准备额外运行 53 项登录会话与禁用媒体下载回归，全部通过；前端 TypeScript 和 Vite 生产构建通过。依赖仍有两项既有弃用提示。

真实账号的连续三次登录恢复、跨天保持登录、重启电脑、干净 Windows 10/11、缺失 WebView2、离线安装组合以及全新模型 Agent 的独立使用仍待验收。安装包未代码签名，本次以预览版发布，不宣称稳定版或平台永久免登录。自动更新源尚未启用，当前通过发行页手动下载安装。

## 旧版与数据

7 月学习版与新版的程序目录不同。新版不删除或自动导入旧文件，已有数据可按需导入；本机 0.1.x 的任务、数据与登录资料继续保存在 `%LOCALAPPDATA%/MediaWorkbench/data`。清理任务记录保留登录信息；“忘记此账号”是单独的明确操作。

公开源码与发行包仅包含程序和合成示例，不包含个人采集结果、访问凭据、浏览器档案或登录快照。源代码来自本地已验证工作树的文件快照，公开仓库保留原有提交历史，不导入开发机的历史数据或构建缓存。

## 构建

在干净源码目录中运行 `packaging/build-windows-release.ps1`。锁文件固定 Python/Node/SDK 依赖；`build-manifest.json` 将二进制文件清单关联到公开源码提交，`SHA256SUMS.txt` 用于核对下载附件。构建不会启用原上游的 Pages 部署或赞助配置。
