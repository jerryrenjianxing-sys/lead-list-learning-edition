# 任务记录清理与抖音登录弹窗修复

2026-09-22，本机“汇川技术”抖音采集任务在登录阶段失败，尚未进入内容采集和媒体下载。

## 原因与处理

任务日志显示新版 `login-full-panel-*` 登录弹窗已出现，但旧逻辑只检查 `login-panel-new`，随后点击被弹窗覆盖的“登录”按钮，最终超时。修复后识别新旧可见弹窗及二维码容器，已有弹窗时不再点击背后按钮；点击期间自动出现弹窗也可正常接续。页面交互超时单独提示，不再统一称为网络错误。

额外检查确认原登录 Cookie 仍在本机浏览器中。第一次诊断时，浏览器同源查询与采集客户端分别返回 `status_code=8`（用户未登录）；等待页面稳定后结果相同。随后用户准备重新登录，恢复原任务的第 2 次运行时，初次服务端认证已成功，任务继续采集。不能用 Cookie 文件存在或之前成功的任务记录代替每次运行的当前认证。

## 界面与清理

- 此轮曾将“下载媒体”改为“下载图片 / 视频”并添加说明；用户随后要求取消该功能，现已移除，见[媒体下载移除记录](media-download-removal.md)。
- 任务记录支持逐条清理、一键清理已结束任务、恢复已清理记录。不会清理正在运行、停止中或排队任务。
- 清理是可恢复的列表归档，保留采集数据、原始文件、分析成果、登录信息及诊断日志，不承诺释放磁盘空间。通过任务 ID 仍能查看记录；恢复执行会将其重新放回列表。
- 登录任务显示“登录验证”，避免把 `login` 暴露给用户。
- SQLite 升级到版本 3，新增 `job_history_archive`；升级前备份，后台空闲时才更新本机版本。
