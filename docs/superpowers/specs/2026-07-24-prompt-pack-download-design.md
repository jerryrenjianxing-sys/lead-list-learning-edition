# 数据管理 Prompt 整合包提示设计

## 目标

提醒用户把采集资料和 Prompt 整合包一起发送给分析 Agent，并让整合包可以直接从数据管理弹窗下载。

## 页面改动

- 在数据管理弹窗顶部操作区下方、分类按钮上方显示一行提示。
- 文案为：`请将「打包下载当前列表」获得的采集资料，与「下载 Prompt 整合包」一起发送给 Agent。`
- `下载 Prompt 整合包`为可点击链接，点击后下载用户提供的 ZIP。

## 文件与范围

- 将用户提供的 ZIP 复制为前端静态文件，使用稳定路径，后续更新时可直接替换。
- 只修改前端，不改 API、数据打包逻辑、爬虫任务或后端代码。
- 不把采集资料和 Prompt 整合包重新合并成一个 ZIP。

## 验收

- 数据管理弹窗可看到完整提示。
- 点击链接能下载 ZIP，且 ZIP 可以正常打开。
- 原有“打包下载当前列表”“重新扫描”和文件列表功能不受影响。
- 前端构建通过。
