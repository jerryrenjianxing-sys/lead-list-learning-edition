# 公开账号与数据质量

在需要账号定位、潜客名单或补采时读取。以下是项目已有 MediaCrawler 数据字段约定；先检查本批原始结构，字段名相似不代表账号类型相同。API 的记录 `id` 是软件记录编号，既不是平台账号也不是评论 ID。

## 关联与标识

评论、回复与 profile 只按同平台稳定账号 ID 精确关联。评论与 raw 按同平台评论 ID 匹配，保留来源任务；同名或相同头像不能作为账号合并依据。输出需要区分公开账号、标识类型、内部 ID、哈希、原始字段路径、主页链接与资料状态。

旧版原始记录内的字段按下表提取。经 API 读取时先进入记录的 `payload`，再按其实际结构查找；不要机械地多套或少套一层。

| 平台 | 可接受来源及顺序 | 不能冒充的字段 |
|---|---|---|
| 抖音 | 评论自身明确标注的 `payload.publicId`；否则同账号 profile 的 `payload.user.unique_id`；为空或 `"0"` 时使用有效 `short_id`，或明确同义公开字段。类型写“抖音号”。 | `accountId`、`uid`、`sec_uid/sec_user_id`、`MS4wLjAB...`、哈希。 |
| 小红书 | 明确的评论 `payload.publicId`；否则同账号 profile 的 `payload.basicInfo.redId` 或明确的 `red_id`。类型写“小红书号”。 | `accountId`、`user_id`、`xsec_token`、哈希。 |
| 快手 | 明确的评论 `payload.publicId`；否则同账号 profile 的 `payload.sensitiveUserInfo.kwaiId`、`payload.sensitiveInfo.kwaiId`、`payload.profile.kwaiId` 或明确命名为 `kwai_id/kuaishou_id` 的公开字段。类型写“快手号”。 | `user_id/userId`、`accountId`、`authorId/author_id`、哈希。不能因值长得像账号就认定为快手号。 |
| 哔哩哔哩 | 原数据明确返回的 `mid` 等公开 UID，类型写“B站 UID”。 | 内容 ID、评论 ID、匿名哈希。 |
| 微博 | 原数据明确返回的账号公开 UID 或公开主页标识，注明真实类型。 | 帖子 ID、昵称、哈希。 |
| 知乎 | 明确返回的 `url_token`，类型写“知乎主页标识”。 | 昵称、评论 ID、哈希。 |
| 贴吧 | 明确公开用户名，或主页 `portrait`；分别注明“贴吧公开用户名”或“贴吧主页标识”。 | 昵称、评论 ID、哈希。 |

公开 UID 在部分平台同时可作为内部关联键，因此不能简单用“与内部 ID 相同”判假；关键是字段是否确实被平台定义为公开标识，以及是否标注真实类型。当前批次字段若与约定不符，保留原始路径并说明待核实，不能靠推测填号。

主页优先使用原始 profile/sourceUrl/profileUrl，保留平台需要的访问参数；仅能定位主页不等于取得公开号。访问令牌不是账号字段，不能放进公开号列。账号与长 ID 写入 Excel 时用文本，保留前导零；不生成科学计数法或日期。

## 缺失与补采

可用资料状态：已取得明确公开账号、仅主页可定位、待补采主页、未匹配账号、数据异常。缺失公开号留空；已纳入的业务候选可以进入补采清单，保留平台、内部定位 ID、主页、证据与缺失原因。

根据 capabilities 判断补采能力；目前 profile enrichment 仅声明支持小红书、抖音、快手，且真实平台验收状态需查看返回值。补采是否执行取决于用户任务范围和实际能力，不能承诺每个平台都能取到号。登录、失败和部分完成如实记录，不让一个缺失字段抹掉已有业务证据。

## 分开计算成功指标

- 评论匹配率：精确匹配到 raw 的去重评论数 ÷ 需要 raw 匹配的去重评论数；没有这类来源时标注不适用。
- 主页覆盖率：有精确匹配 profile 的唯一结果账号数 ÷ 唯一结果账号数。
- 公开号覆盖率：有明确公开账号的唯一结果账号数 ÷ 唯一结果账号数。
- 处理覆盖率：采用软件分析快照的 coverage，区分 processed、pending、failed 和 skipped；不能拿候选数量代替处理量。
- 语义准确率：只有存在人工标签和明确抽检范围时才计算，报告样本分子分母；否则为未验证。

每个平台分别列分子、分母，再做去重后的总计。分母为零时写不适用，不能写 100%。评论匹配、主页可定位或内部 ID 非空都不能替代公开号覆盖率；历史样本数字不能作为当前批次成功率。
